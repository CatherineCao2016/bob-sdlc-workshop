Setup · JDK & Maven
Install the JDK and Maven
Get a JDK (17 or later) and Maven 3.6+ on your PATH.
💬 What you're installing
  • The JDK (Java Development Kit) compiles and runs Java code. The workshop app needs JDK 17 or later. Any distribution works: Eclipse Temurin, Amazon Corretto, Microsoft Build of OpenJDK, or Oracle JDK.
  • Maven is the build tool. It compiles the project, resolves dependencies, and starts the app with mvn spring-boot:run. You need Maven 3.6 or newer.
  • You do not install Spring Boot yourself. It's declared in the project's pom.xml, and Maven downloads it (and everything else) from Maven Central on the first build.
  • Pick the section for your operating system below, then jump to Verify your install to confirm both are on your PATH.
Install by Operating System
1
macOS
The simplest path is Homebrew. Install the Temurin JDK and Maven; Homebrew handles Apple Silicon (M-series) and Intel automatically. 
brew install temurin   # Eclipse Temurin JDK (latest LTS)
brew install maven     # Maven (pulls in a JDK dependency too)

# confirm both are on your PATH
java -version
mvn -version
📝 Note
To pin a specific Java version, use a versioned cask, e.g. brew install temurin@17. If java -version still shows an old version afterward, set JAVA_HOME with export JAVA_HOME=$(/usr/libexec/java_home -v 17) in your ~/.zshrc.
2
Windows
Use a package manager, or download the installers. With WinGet (built into Windows 11): 
winget install --id EclipseAdoptium.Temurin.17.JDK
winget install --id Apache.Maven
With Scoop or Chocolatey: 
# Scoop
scoop bucket add java
scoop install temurin17-jdk maven

# Chocolatey (run in an elevated prompt)
choco install temurin17 maven
Or the installers. Download the JDK from adoptium.net (the .msi sets JAVA_HOME and PATH for you), and Maven from maven.apache.org.
📝 Note
After installing, open a new terminal (PowerShell or Command Prompt) so it picks up the updated PATH, then run the verification commands below. If you used the Maven .zip manually, add its bin folder to your PATH and set JAVA_HOME to the JDK folder.
3
Linux
On Debian/Ubuntu, install from the package repositories: 
sudo apt update
sudo apt install openjdk-17-jdk maven -y

java -version
mvn -version
📝 Note
On Fedora/RHEL use sudo dnf install java-17-openjdk-devel maven. On Arch, sudo pacman -S jdk17-openjdk maven. Across distros, SDKMAN! is a great way to install and switch between JDK and Maven versions: sdk install java then sdk install maven.
Verify your install
4
Confirm both are on your PATH
Run both commands in a terminal. You should see JDK 17 or later and Maven 3.6 or newer, and the Maven output should report the same Java version it's using. 
# JDK: look for "17", "21", or higher
java -version

# Maven: look for "Apache Maven 3.6+" and a matching Java version line
mvn -version
Typical output looks like: 
openjdk version "17.0.10" 2024-01-16
OpenJDK Runtime Environment Temurin-17.0.10+7 ...

Apache Maven 3.9.6 ...
Java version: 17.0.10, vendor: Eclipse Adoptium ...
💡 Tip
If a command is "not found," your install isn't on the PATH yet: open a new terminal, or check that JAVA_HOME points at the JDK and that Maven's bin folder is on the PATH. If mvn -version reports an older Java than you expect, fix JAVA_HOME so it points at your JDK 17+ install. Once both commands report the right versions, you're ready to start Lab 1.
