Backup Prompts
Resource optimization, DR readiness, MCP integration vision
Prerequisites
✅ Before You Start
  1. Earlier labs completed, so the payment app is deployed in the bob-demo namespace and you have the Bob IDE open.
  2. These prompts are optional extras for Q&A or spare time; each one stands alone, so run them in any order.
💬 OVERVIEW
We went from zero to a production-deployed, security-scanned, pipeline-automated application with automated Day-2 operations, in 10 minutes. Everything I did by typing prompts? In production, this runs automatically through Bob's CLI in your CI pipeline. The intelligence is the same. The human is optional.
Step-by-Step
1
Try the resource optimization prompt
Send the prompt below to have Bob review resource requests and limits across the bob-demo deployments. It flags over-provisioned and under-provisioned pods and recommends right-sized values based on actual usage.
Prompt · Resource Optimization
▼
Analyze resource requests and limits for all deployments in bob-demo. Identify pods that are over-provisioned (using <50% of requested CPU/memory) and under-provisioned (hitting limits). Recommend right-sized values based on actual usage over the last 24 hours.
2
Try the DR readiness prompt
This prompt asks Bob to audit disaster recovery readiness for the namespace: GitOps coverage, secret replication, PVC backups, and config drift between clusters. It finishes by generating a DR runbook for payment-service.
Prompt · DR Readiness
▼
Validate disaster recovery readiness for the bob-demo namespace. Check: are all deployments backed by Git (GitOps)? Are secrets replicated? Are PVCs backed up? Is there config drift between primary and DR clusters? Generate a DR runbook for payment-service.
3
Try the MCP integration vision prompt
Use this one when the discussion turns to "how does Bob fit our existing toolchain?" It asks Bob to design an MCP server configuration that wraps Wiz, GitHub, Vault, and ArgoCD, and to show how it would call those tools autonomously in a security gate workflow.
Prompt · MCP Integration Vision
▼
Design an MCP server configuration that wraps our existing tools: - Wiz API for security scanning - GitHub API for PR management - HashiCorp Vault for secrets - ArgoCD for deployment status Show how Bob would call these tools autonomously during a security gate workflow without human intervention.
4
Close with the summary report prompt
A strong way to end the session: ask Bob to recap everything the workshop produced, with a risk assessment and recommended next steps. Bob writes the wrap-up for you.
Prompt · Closing Summary
▼
Generate a summary report of everything we did today. Show: what was built, what was scanned, what was fixed, what was deployed, and what was automated. Include a risk assessment and recommendations for next steps.
