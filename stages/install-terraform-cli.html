Setup · Terraform CLI
Install the Terraform CLI
Get the Terraform command-line tool on macOS, Windows, or Linux. It's the only local tool Lab 5 needs to run fmt and validate.
💬 What you're installing
  • terraform is a single self-contained binary from HashiCorp that behaves identically on macOS, Windows, and Linux, so the commands in Lab 5 work the same everywhere.
  • In Lab 5 you only run terraform fmt, terraform init -backend=false, and terraform validate. These are offline checks: no cloud account, no OpenShift cluster, and no terraform apply are required to complete the lab.
  • Pick the section for your operating system below. Any recent version works; the lab was verified on Terraform v1.14.
Install by Operating System
1
macOS
The simplest path is Homebrew. It installs the right build for Apple Silicon (M-series) or Intel automatically. 
brew tap hashicorp/tap
brew install hashicorp/tap/terraform

# confirm it's on your PATH
terraform -version
Upgrading later. If you already have it via Homebrew, update with: 
brew update
brew upgrade hashicorp/tap/terraform
Without Homebrew. Download the macOS zip from HashiCorp, unzip it, and move terraform onto your PATH. 
# Apple Silicon: use the darwin_arm64 zip. Intel: use darwin_amd64.
curl -LO https://releases.hashicorp.com/terraform/1.14.5/terraform_1.14.5_darwin_arm64.zip
unzip terraform_1.14.5_darwin_arm64.zip
sudo mv terraform /usr/local/bin/
terraform -version
📝 Note
On a Mac, the first time you run a downloaded binary you may need to approve it under System Settings > Privacy & Security. Homebrew installs avoid this prompt.
2
Windows
The easiest path is a package manager. If you use Chocolatey or Scoop, let it handle the download and PATH for you. 
# Chocolatey (run in an elevated prompt)
choco install terraform

# Scoop
scoop install terraform

terraform -version
Manual install. Download the Windows zip, extract it, and add the folder that contains terraform.exe to your PATH. Once it's on the PATH, terraform works in both PowerShell and Command Prompt. 
# 1. Download this file in a browser:
#    https://releases.hashicorp.com/terraform/1.14.5/terraform_1.14.5_windows_amd64.zip
# 2. Extract it, e.g. to C:\terraform
# 3. Add C:\terraform to your PATH:
#    Start menu -> "Edit the system environment variables"
#    -> Environment Variables -> select "Path" -> Edit -> New -> C:\terraform -> OK
# 4. Open a NEW terminal so the PATH change takes effect, then:
terraform -version
3
Linux
On Debian/Ubuntu, add the official HashiCorp apt repository so you also get future updates through apt. 
wget -O- https://apt.releases.hashicorp.com/gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] \
  https://apt.releases.hashicorp.com $(lsb_release -cs) main" | \
  sudo tee /etc/apt/sources.list.d/hashicorp.list

sudo apt update && sudo apt install terraform
terraform -version
Any distro (manual). Download the Linux zip, unzip it, and move terraform into a directory on your PATH. 
# x86_64: use linux_amd64. ARM: use linux_arm64.
curl -LO https://releases.hashicorp.com/terraform/1.14.5/terraform_1.14.5_linux_amd64.zip
unzip terraform_1.14.5_linux_amd64.zip
sudo mv terraform /usr/local/bin/
terraform -version
📝 Note
On Fedora/RHEL use dnf with the HashiCorp repo (sudo dnf install -y dnf-plugins-core && sudo dnf config-manager --add-repo https://rpm.releases.hashicorp.com/fedora/hashicorp.repo && sudo dnf install terraform), or use the manual zip path above.
Verify
4
Verify the install
Confirm terraform is on your PATH and runnable. You should see a version line; anything v1.0 or newer is fine for this lab. 
terraform -version
Expected output looks like: 
Terraform v1.14.5
on darwin_arm64
💡 Tip
If the shell reports command not found, the binary isn't on your PATH yet. Re-open your terminal (so PATH changes take effect), or confirm you moved terraform into a directory that's on your PATH such as /usr/local/bin.
