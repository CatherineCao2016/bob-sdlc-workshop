Setup · GitHub CLI
Install the GitHub CLI
Get the gh command-line tool on macOS, Windows, or Linux. Lab 7's launch script uses it to set repo secrets, variables, and the production approval gate.
💬 What you're installing
  • gh is GitHub's official CLI. It talks to the GitHub API from your terminal, which is how Lab 7's launch-pipeline.sh sets Actions secrets and variables, creates the production environment, and watches the run, all without clicking through the web UI.
  • After installing, you authenticate once with gh auth login. The CLI stores its own session, so the launch script never sees or stores your credentials; it just reuses that session.
  • Pick the section for your operating system below, then run gh auth login to finish.
Install by Operating System
1
macOS
The simplest path is Homebrew. It installs the right build for Apple Silicon (M-series) or Intel automatically. 
brew install gh

# confirm it's on your PATH
gh --version
With MacPorts. If you use MacPorts instead: 
sudo port install gh
2
Windows
Use a package manager, or download the installer. With WinGet (built into Windows 11): 
winget install --id GitHub.cli
With Scoop or Chocolatey: 
# Scoop
scoop install gh

# Chocolatey (run in an elevated prompt)
choco install gh
Or the installer. Download the latest .msi from the gh releases page, run it, then open a new terminal and run gh --version.
3
Linux
On Debian/Ubuntu, add the official GitHub CLI apt repository so you also get future updates through apt. 
(type -p wget >/dev/null || sudo apt update && sudo apt install wget -y)
sudo mkdir -p -m 755 /etc/apt/keyrings
wget -qO- https://cli.github.com/packages/githubcli-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg >/dev/null
sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] \
  https://cli.github.com/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/github-cli.list >/dev/null
sudo apt update && sudo apt install gh -y
gh --version
📝 Note
On Fedora/RHEL use sudo dnf install gh (or sudo dnf install 'dnf-command(config-manager)' then add the https://cli.github.com/packages/rpm/gh-cli.repo repo first). On Arch, sudo pacman -S github-cli.
Authenticate
4
Log in to GitHub
Confirm the install, then authenticate. gh auth login walks you through an interactive sign-in (it can open a browser or accept a token). 
gh --version

# interactive sign-in: choose GitHub.com, HTTPS, and "Login with a web browser"
gh auth login

# confirm you're signed in
gh auth status
💡 Tip
When prompted, choose HTTPS as the git protocol so pushes use your gh session. Lab 7's launch script also runs gh auth setup-git to wire that up. If you need to push to a repo, make sure your login has access to it.
